# 1. 성공한 AI 서비스 분해·조립해보기

## 1.1 AI 서비스 리버스 엔지니어링

**리버스 엔지니어링(Reverse Engineering)** 이란 이미 성공한 AI 서비스를 역방향으로 분석하여 비즈니스가 작동하는 원리를 파악하는 방법이다.

- 일반적인 접근: 아이디어 구상 → AI 모델 개발 → 고객 탐색
- 역방향 접근: 성공한 AI 서비스 분석 → 수익 구조 분석 → 고객 문제 발견

**핵심 분석 요소**
1. 고객 문제(Pain Point)
2. AI 기술과 해결책(Technology & Value)
3. 수익 구조(Revenue Model)

## 1.2 사례: 오늘의집 AI

### 주요 서비스
| 기능 | 설명 |
|---|---|
| Space AI | 방 사진을 분석해 다양한 인테리어 스타일로 변환 |
| 3D 룸플래너 | 가구 배치를 입체적으로 체험 |
| 맥락 기반 상품 추천 | 사진 속 가구와 유사한 구매 가능 상품 추천 |
| CX Copilot | 리뷰 분석 및 고객 상담 답변 초안 생성 |

### STEP 1. 고객 문제 분석

| 고객의 불편 | 문제점 |
|---|---|
| 가구 배치 예측 불가 | 구매 전 방과 어울릴지 확신하기 어려움 |
| 상품 탐색 피로 | 사진 속 마음에 드는 가구를 찾기 어려움 |
| 고객 응답 지연 | 배송 및 시공 문의 처리에 시간이 오래 걸림 |

### STEP 2. AI 기술과 해결책 연결

| AI 기술 | 적용 기능 | 고객 가치 |
|---|---|---|
| Computer Vision | 공간 문맥 분석 및 유사 상품 탐색 | 적합한 가구 검색 |
| Generative AI | 가상 인테리어 이미지 생성 | 구매 실패 위험 감소 |
| LLM Copilot | 상담 답변 초안 자동 생성 | 고객 응답 속도 개선 |

강의자료에서는 상담 답변 시간이 4분에서 20초로 줄어드는 사례를 제시한다.

### STEP 3. 수익 모델 분석

1. **커머스 수수료**: AI 추천을 통해 상품 구매가 발생하면 수수료 수익 창출
2. **맞춤형 광고**: 이용자의 관심사를 기반으로 입점사 광고 노출
3. **시공 중개 수수료**: 3D 룸플래너와 전문 시공업체 연결

### 데이터 선순환 구조(Flywheel)

사용자 공간 사진 업로드
→ AI 인테리어 생성
→ 연관 상품 구매
→ 공간 및 관심 데이터 축적
→ 상품 추천 정교화
→ 사용자 경험과 구매 전환 개선

**핵심:** AI 기술 자체보다 고객 문제를 해결하고 실제 수익으로 연결하는 구조가 중요하다.

# 2. 아이디어 보호와 지식재산권

## 2.1 지식재산권의 중요성

4차 산업혁명으로 제조업과 인터넷이 융합되고 경쟁이 글로벌화되면서 기업은 혁신 기술을 지식재산으로 보호하여 경쟁우위를 확보한다.

지식재산권은 초기 창업기업의 기술 보호뿐만 아니라 자금 조달, 투자 유치, 마케팅 등에 활용된다.

## 2.2 지식재산권 활용 방법

| 활용 분야 | 설명 |
|---|---|
| 창업지원 자금 | 정부 지원사업과 금융기관 융자 평가에 활용 |
| 정부 R&D 자금 | 기술성 평가에서 경쟁력 확보 |
| 투자 유치 | 기술력과 자산 가치를 투자자에게 제시 |
| 마케팅 | 특허 기술을 통해 브랜드 신뢰도 강화 |
| 기술거래 | 특허 매매 또는 라이선스 계약으로 수익 창출 |
| 인증 | 관련 인증 및 지원제도 활용 |

### 기술거래 방식

- **특허권 매매:** 특허 소유권 자체를 다른 사람이나 기업에 이전한다.
- **라이선스:** 특허 소유권은 유지하면서 다른 기업에 기술 사용을 허락하고 로열티를 받는다.

## 2.3 산업재산권의 종류

| 구분 | 보호 대상 | 예시 |
|---|---|---|
| 특허권 | 고도한 기술적 발명 | 새로운 AI 영상처리 기술 |
| 실용신안권 | 물품의 형상·구조 또는 조합에 관한 고안 | 개선된 기계 구조 |
| 디자인권 | 물품 등의 디자인 | 제품 외관 디자인 |
| 상표권 | 상품이나 서비스의 출처를 구별하는 표장 | 서비스 브랜드명과 로고 |

※ 예시는 개념 이해를 위한 보충 설명이다.

## 2.4 특허 성립의 3가지 조건

### ① 신규성(Novelty)
- 기존에 공개된 기술과 구별되는 새로운 발명이어야 한다.
- 이미 공개되어 신규성을 잃은 발명은 원칙적으로 특허를 받기 어렵다.

### ② 진보성(Inventive Step)
- 해당 기술 분야의 통상적인 전문가가 기존 기술로부터 쉽게 생각해 낼 수 없어야 한다.
- 기존 기술과의 차이 및 기술적 효과를 살펴본다.

### ③ 산업상 이용가능성(Industrial Applicability)
- 발명을 산업적으로 이용할 수 있어야 한다.
- 실질적으로 산업에서 활용 가능한 기술이어야 한다.

**암기: 신규성 + 진보성 + 산업상 이용가능성**

## 2.5 특허 취득 절차

1. 선행기술 조사
2. 특허명세서 작성
3. 특허 출원
4. 심사 절차 진행
5. 등록 여부 결정

**특허명세서:** 보호받으려는 발명의 기술적 내용을 명확하고 상세하게 작성한 문서

## 2.6 효과적인 특허 창출 전략

### ① 선행기술 분석
- 유사한 기술이나 기존 특허가 존재하는지 조사한다.
- 기존 기술과 차별화되는 요소를 추가한다.
- 특허 획득 목적과 활용 방법을 구체화한다.

### ② 구성요소 재결합

| 전략 | 구조 | 설명 |
|---|---|---|
| 부가 | A+B+C → A+B+C+D | 새로운 기능이나 요소 추가 |
| 치환 | A+B+C+D → A+B+C+D' | 기존 구성요소를 다른 기술로 대체 |
| 삭제 | A+B+C+D → A+B+C | 기능을 유지하면서 불필요한 구성요소 제거 |

### ③ 특허청구범위 설정

**특허청구범위(Claims)** 는 발명에 대해 법적으로 보호받고자 하는 범위를 정하는 것이다.

- 기존 특허와 충돌하지 않아야 한다.
- 발명의 기술적 특징을 명확하게 작성한다.
- 법적 요건을 충족하는 범위에서 가능한 한 효과적인 보호범위를 확보한다.

# 3. 창업 실무 절차

## 3.1 회사의 설립 형태

창업 시 먼저 개인기업과 법인기업 중 어떤 형태로 운영할지 결정한다.

| 비교 항목 | 개인기업 | 법인기업 |
|---|---|---|
| 법적 주체 | 사업자 개인 | 법인 자체 |
| 책임 | 사업주 개인에게 귀속 | 원칙적으로 법인에 귀속 |
| 과세 | 종합소득세 | 법인세 |
| 설립 절차 | 비교적 간단 | 법인 설립등기 필요 |
| 폐업 절차 | 폐업신고 등 | 해산 및 청산 절차 필요 |

※ 법인 형태와 구체적인 상황에 따라 대표자·주주의 책임은 달라질 수 있다. 강의자료에 나온 과거 세율 수치는 현행 세법과 다를 수 있으므로 별도로 확인해야 한다.

## 3.2 개인기업 설립 절차

1. 사업 업종 결정
2. 인허가 대상 업종인지 확인
3. 필요한 인허가·등록·신고 진행
4. 사업자등록 신청

**사업자등록:** 원칙적으로 사업 개시일로부터 20일 이내 신청

## 3.3 법인기업 설립 절차

1. 발기인 구성
2. 정관 작성
3. 주식 인수 및 주금 납입
4. 법인 설립등기
5. 법인설립 신고 및 사업자등록
6. 해당 업종의 인허가 확인
7. 근로자 고용 등 해당 요건에 따른 4대 보험 신고

**법인 사업자등록:** 강의자료에서는 설립등기 후 20일 이내 신청하는 절차를 설명한다.

## 3.4 사업 인허가

업종에 따라 관련 기관의 허가, 등록 또는 신고가 필요할 수 있다.

- **허가:** 관할 기관의 허가가 필요한 업종
- **등록:** 법령에서 정한 등록 요건을 충족해야 하는 업종
- **신고:** 관할 기관에 법정 사항을 신고해야 하는 업종

실제 사업을 시작하기 전에 해당 업종에 적용되는 인허가 요건을 확인해야 한다.

## 3.5 벤처기업

**벤처기업:** 새로운 기술과 아이디어를 사업화하며 높은 위험을 감수하지만 높은 성장성과 수익을 기대하는 기술집약형 중소기업

### 특징
- 혁신 기술 및 아이디어 중심
- 높은 위험과 높은 성장 가능성
- 기술 사업화 추진
- 기업가정신과 도전성

### 벤처기업 확인
1. 벤처기업 요건 검토
2. 관련 신청 서식 작성
3. 벤처기업 확인 신청
4. 평가 및 확인 절차 진행

강의자료는 벤처기업 확인 신청 시스템인 '벤처인'을 소개한다.

## 3.6 기업부설연구소 및 연구개발전담부서

### 설립 목적
- 연구개발(R&D) 역량 강화
- 신제품 및 신기술 개발
- 우수 연구인력 확보
- 기술경쟁력 강화

일정 요건을 갖추어 신고한 기업부설연구소와 연구개발전담부서는 관련 지원제도를 활용할 수 있다.

## 3.7 기술혁신형 중소기업(Inno-Biz)

**Inno-Biz = Innovation + Business**

기술 경쟁력과 미래 성장 가능성을 갖춘 기술혁신형 중소기업을 의미한다.

정부는 관련 제도를 통해 기술, 자금, 판로 등 다양한 분야의 지원을 연계한다.

# 4. 핵심 개념 요약

| 용어 | 핵심 의미 |
|---|---|
| 리버스 엔지니어링 | 성공 서비스를 역방향으로 분석 |
| Pain Point | 고객이 겪는 불편과 문제 |
| Computer Vision | 이미지와 영상의 정보 분석 |
| Generative AI | 새로운 이미지·텍스트 등 생성 |
| LLM Copilot | 언어모델 기반 업무 지원 |
| Revenue Model | 수익을 창출하는 구조 |
| Flywheel | 데이터와 성과가 반복적으로 강화되는 선순환 |
| 지식재산권 | 지식과 창작·발명을 보호하는 권리 |
| 신규성 | 새로운 발명인지 판단 |
| 진보성 | 기존 기술로부터 쉽게 발명할 수 없는지 판단 |
| 산업상 이용가능성 | 산업적으로 이용할 수 있는지 판단 |
| 특허청구범위 | 특허의 법적 보호범위 |
| 벤처기업 | 혁신 기술 기반의 고위험·고성장형 기업 |
| 기업부설연구소 | 기업 내 연구개발 조직 |
| Inno-Biz | 기술혁신형 중소기업 |

## 시험 대비 핵심 암기

1. **AI 비즈니스 분석 3단계:** 고객 문제 → AI 기술과 가치 → 수익 구조
2. **오늘의집 AI 수익 모델:** 커머스 수수료, 맞춤형 광고, 시공 중개 수수료
3. **지식재산권 활용:** 자금 조달, R&D, 투자, 마케팅, 기술거래, 인증
4. **산업재산권 4종:** 특허권, 실용신안권, 디자인권, 상표권
5. **특허 성립 3요건:** 신규성, 진보성, 산업상 이용가능성
6. **특허 창출 전략:** 선행기술 분석, 구성요소 부가·치환·삭제, 청구범위 설정
7. **기업 유형:** 개인기업과 법인기업
8. **창업 실무:** 기업 유형 결정 → 설립·등록 → 인허가 및 관련 신고
9. **벤처기업:** 혁신 기술의 사업화와 높은 성장 가능성
10. **Inno-Biz:** 기술혁신형 중소기업
